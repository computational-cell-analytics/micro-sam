# Training Data References for the μSAM2 `_em_nuclei` Models

Training data of `hvit_s_em_nuclei` (`dataset_choice="em_nucleus"`, see `EM_NUCLEUS_DATASETS` in `micro_sam/v2/datasets/generalist_loader.py`). One citation for each dataset: the publication, or the data record if there is no publication.

- **BetaSeg**: [10.1083/jcb.202010039](https://doi.org/10.1083/jcb.202010039)
- **CellMap**: [10.25378/janelia.c.7456966](https://doi.org/10.25378/janelia.c.7456966) — The CellMap Segmentation Challenge data collection.
- **Human organoids**: [10.1016/j.devcel.2023.03.001](https://doi.org/10.1016/j.devcel.2023.03.001)
- **SXT INS-1E**: [10.64898/2026.03.19.712811](https://doi.org/10.64898/2026.03.19.712811) — Soft X-ray tomography, not EM.
- **FAFB nuclei**: [10.1101/2021.11.04.467197](https://doi.org/10.1101/2021.11.04.467197)
- **Janelia nuclei**: [10.17504/protocols.io.n2bvjnq8pgk5/v1](https://doi.org/10.17504/protocols.io.n2bvjnq8pgk5/v1) — The Cellpose protocol of the labels. The 3 `jrc_mus-nacc` volumes have manual labels ([10.17504/protocols.io.bp2l61rb5vqe/v3](https://doi.org/10.17504/protocols.io.bp2l61rb5vqe/v3)).
- **MICrONS minnie65**: [10.1038/s41586-025-08790-w](https://doi.org/10.1038/s41586-025-08790-w)
- **WAE-Net** (datasets 1 and 3-7): [10.1007/s00418-022-02148-3](https://doi.org/10.1007/s00418-022-02148-3)
- **Platynereis**: [10.1016/j.cell.2021.07.017](https://doi.org/10.1016/j.cell.2021.07.017)
- **Tumor spheroid EM**: [10.64898/2026.04.17.719153](https://doi.org/10.64898/2026.04.17.719153)
- **OpenOrganelle**: [10.1038/s41586-021-03977-3](https://doi.org/10.1038/s41586-021-03977-3) — The OpenOrganelle publication. Some of the volumes are not part of it.
- **Cardiomyocyte TEM**: [10.1016/j.crmeth.2025.101212](https://doi.org/10.1016/j.crmeth.2025.101212)
- **microSAM EM nuclei**: [10.5281/zenodo.14037020](https://doi.org/10.5281/zenodo.14037020)
- **Perez**: [10.3389/fnana.2014.00126](https://doi.org/10.3389/fnana.2014.00126)
- **vEM nuclei** (NucleoNet): [10.64898/2026.04.02.713930](https://doi.org/10.64898/2026.04.02.713930) — The data is BioImage Archive [S-BIAD2822](https://www.ebi.ac.uk/biostudies/studies/S-BIAD2822), which has no DOI.
- **Cerebellum FIB-SEM**: [10.5281/zenodo.18886823](https://doi.org/10.5281/zenodo.18886823)
- **Macrophage / A431**: [10.1038/s44318-025-00423-2](https://doi.org/10.1038/s44318-025-00423-2)
