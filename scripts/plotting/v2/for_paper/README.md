# Plotting Scripts for the micro-sam2 Paper

This directory has the python scripts that make the figures for the `micro-sam2` paper.

## Scripts

- `plot_style.py`: The shared plot style and the fixed color of each method. All figures import their colors from here.
- `plots_for_figure1.py`: Plots for Figure 1.
- `plots_for_figure2.py`: All plots for Figure 2, automatic and interactive, quantitative and qualitative.
- `plots_for_figure3.py`: Plots for Figure 3.
- `plots_for_figure4.py`: Plots for Figure 4, object and pixel classification with the features of each model over the number of labels, and the mean rank of the feature models.
- `plots_for_figure5.py`: Plots for Figure 5.
- `plots_for_figure6.py`: Plots for Figure 6.
